# Lista de tarefas

To-do list simples em HTML, CSS e JavaScript puro. Da pra adicionar uma tarefa,
clicar nela pra marcar como concluida (risca o texto) e remover com o botao ao
lado. Tudo fica salvo no localStorage do navegador, entao a lista continua la
depois de fechar a aba.

## O que pratiquei

- Manipulacao do DOM (`createElement`, `appendChild`, `classList`)
- Evento de `submit` de formulario e `preventDefault`
- `localStorage` com `JSON.stringify` / `JSON.parse`
- CSS basico com flexbox

## Como rodar

Abre o `index.html` direto no navegador. Nao precisa de servidor nem instalar nada.
